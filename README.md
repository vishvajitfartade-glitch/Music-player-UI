# 🎵 SurTaal - Hindi Music Player

A modern and responsive Hindi Music Player UI created using HTML5, CSS3 and Vanilla JavaScript.

## 📌 Internship Task

**Day 19 - Music Player UI**

---

## 🎯 Project Objective

The objective of this project is to create a functional music player interface using the HTML5 Audio API.

The player provides a simple and attractive Hindi music themed interface with playback controls, playlist management and audio progress tracking.

---

## ✨ Features

- 🎵 Hindi music themed UI
- ▶️ Play / Pause
- ⏮️ Previous song
- ⏭️ Next song
- 🔀 Shuffle
- 🔁 Repeat
- 🎚️ Volume control
- 📊 Progress bar
- ⏩ Seek through song
- 🎶 Hindi playlist
- 🔄 Auto-play next song
- ⌨️ Keyboard controls
- 📱 Responsive design
- 💿 Animated album/vinyl design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Audio API
- Font Awesome
